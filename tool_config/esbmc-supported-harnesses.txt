# Harness families that ESBMC verifies SUCCESSFUL from Kani's CBMC goto-binaries.
#
# One POSIX extended regular expression per line; matched against the mangled
# harness symbol.  Blank lines and lines starting with '#' are ignored.
#
# Adding a line here widens the regression.  Before adding one, confirm that
# *every* harness the expression matches verifies SUCCESSFUL — a family that is
# only partly supported must be narrowed (see the _unchecked_ and f16 carve-outs
# below), otherwise the regression will fail on the members that do not.
#
# Last re-measured 2026-08-26 against esbmc/esbmc master on the corpus generated
# from this tree: 211 harnesses, all SUCCESSFUL, none slower than 5 s.
